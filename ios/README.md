# DLS Magician for iOS

Native SwiftUI container for the production DLS Magician workspace.

- Team ID: `CRFM39M63R`
- Bundle ID: `design.zhenli.dlsmagician`
- Production URL: `https://dlsmagician.empathie.ai`
- Minimum deployment target: iOS 17.0

Open `DLSMagician.xcodeproj` in Xcode, select the DLSMagician scheme, choose a simulator or registered device, and Run. For App Store distribution, select **Any iOS Device (arm64)** and use **Product → Archive**.
