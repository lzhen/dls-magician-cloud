DLS MAGICIAN

Cloud collaboration MVP

This prototype combines passwordless authentication, shared workspaces, a structured-language editor, generated JSON, live workflow preview, comments, permissions, version history, and organization security settings.

Test collaboration

  1. Open the app in two browsers or one normal and one incognito window.
  2. Sign in with different providers; each provider maps to a different demo collaborator.
  3. Open Omnichannel Workflow in both windows.
  4. Edit the structured language, add comments, invite a member, or save a version.
  5. The other window receives the update through Server-Sent Events.

Run locally

npm start
# Open http://localhost:3000

Production note

Authentication uses Supabase. Microsoft and Google require provider credentials in the Supabase dashboard, magic links require configured email delivery, and company SSO requires a verified organization domain.
