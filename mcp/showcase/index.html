Want a standalone local package?

From the repository root, run npm run package:mcp. Install the resulting .tgz with npm on another machine, then run dls-magician-mcp-config. The package contains a versioned design-system snapshot and its stylesheet.

The package is not published to the npm registry. There is no public one-click remote MCP endpoint in this release.
